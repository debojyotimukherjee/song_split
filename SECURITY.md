# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the `develop` branch and the latest published release.

## Reporting a Vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Use GitHub's private vulnerability-reporting flow from the repository's **Security** tab. If private reporting is not enabled, contact the repository owner through their GitHub profile with the subject `Wannabe Stem security report`. Include a concise description, affected version, reproduction steps, and any suggested mitigation. You should receive an acknowledgement within seven days.

Wannabe Stem is a local application with no authentication. Do not expose its Docker port to the public internet. Treat any computer or network user able to access the app as able to upload files and remove local songs.
